Historical Months

Monthly grain — spend/GA4 further back than the two comparison windows above is only available by calendar month, not by arbitrary date range. Google combines Search + PMax (no monthly split available at this grain). Conversions use that month's own SERVCO ÷ GA4-items accuracy ratio.

Methodology
  • Custom conversions = channel GA4 items purchased × accuracy ratio; ratio = SERVCO gross adds ÷ GA4 items purchased across all traffic, computed on the SERVCO-available window (SERVCO Sep 1-22 ÷ GA4 items Sep 1-22). Current: cur: 0.501; cmp: 0.501 (same ratio applied to both windows, per methodology)
  • Custom conv. rate = custom conversions ÷ channel GA4 sessions. Custom CPA = spend ÷ custom conversions.
  • vs LM = month-to-date vs the same elapsed days last month, plain % change, no projection. Run-rate = MTD ÷ elapsed days × days in month, compared against August 2026's full-month actual (vs full LM). Rate metrics (CPC, CPM, CTR, VTR, Conv. rate, CPA) only get vs LM — a rate doesn't scale with days elapsed, so run-rating it would just reproduce the same number.
  • GA4 identifiers (property 282813955): Search = Session campaign starts with "Rocket Mobile_Search"; PMax = contains "Rocket Mobile_Pmax"; Meta = source starts with "facebook", medium "paid-social"; TikTok = "tiktok / paid-social" + "tiktok / consideration-paid-social-cpm"; ChatGPT = "chatgpt_ads / search" + "chatgpt / paid_search"; Twitch = source "amazon-twitch"; Demand Gen = "demandgen / intent-cpm".
  • Platform sources: Google Ads 6066601949 (Supermetrics AW); Meta act_1693880094174879 (FA; platform conversions = custom conversion "OP - Conversion"); TikTok 7538171133322231824 (TIK; plus agency-account months entered manually as tiktok_mbm); ChatGPT Ads, Twitch, Demand Gen = Inputs sheet (manual_channels).
